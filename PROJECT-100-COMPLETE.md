## 🚀 CARA MENJALANKAN

### **1. Prerequisites**
```bash
Node.js 18+
Python 3.11+
Docker & Docker Compose
```

### **2. Start Infrastructure**
```bash
cd infrastructure/docker
docker-compose up -d
```

### **3. Start Backend**
```bash
cd backend
npm install
npm run start:dev
```
- Backend: http://localhost:4000
- Swagger: http://localhost:4000/api/v1/docs

### **4. Start Frontend**
```bash
cd frontend
npm install
# For PDF export functionality:
npm install jspdf jspdf-autotable
npm run dev
```
- Frontend: http://localhost:3000

### **5. Login**
```
Email: admin@festivalmbois.com
Password: admin123
```

### **6. Optional: Run Workers**
```bash
cd workers
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python run_all.py
```
